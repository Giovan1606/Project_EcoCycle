# EcoCycle – Smart Waste Bank

## Project Overview

EcoCycle is a smart digital waste bank platform designed to make recycling more accessible, convenient, and rewarding. The project combines AI-assisted waste identification, flexible waste collection options, a reward system, and environmental impact tracking.

## Problem

Traditional waste bank processes can be inconvenient, less transparent, and provide limited motivation for users to consistently sort and recycle their waste. Users may also have difficulty knowing the value of their recyclable waste and finding convenient collection options.

## Solution

EcoCycle introduces an integrated digital platform with AI Scan & Estimate, Drop Off and Request Pickup options, an EcoReward system, and an Impact Dashboard. These features provide users with transparent waste value estimation, flexible collection methods, and rewards while helping them track their environmental contribution.

## Key Features

- AI Scan & Estimate
- Drop Off & Request Pickup
- EcoReward System
- Environmental Impact Dashboard
- User Activity & Achievement Tracking

## UI/UX Design

The interface was designed using a Human-Centered Design approach, covering research, problem definition, ideation, prototyping, and usability testing. The Figma prototype includes the main user flows such as onboarding, waste scanning, drop-off, pickup, rewards, and impact tracking.
